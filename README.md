# FitBuddy 🏋️

> 你的 AI 健身搭子，记录每一次训练与成长。

## 项目介绍

FitBuddy 是一个基于 WorkBuddy + 腾讯文档的 AI 健身记录助手。

它不负责制定训练计划，而是专注于记录用户真实的健身过程：

- 每日训练日志
- 健身照片记录
- 阶段性突破里程碑
- 月度成长总结

通过 AI 将用户自然语言输入的训练内容整理成结构化记录，并沉淀到腾讯文档中，形成长期可回顾的个人健身成长档案。

## 核心流程

```text
用户记录训练
      ↓
WorkBuddy AI 整理
      ↓
腾讯文档沉淀
      ↓
生成成长记录
```

## 腾讯文档结构

### Workout Log

每日训练记录：

- 日期
- 训练部位
- 动作与重量
- 训练感受
- 训练照片

### Milestones

健身里程碑：

- 重量突破
- 阶段目标完成
- 重要训练节点

### Growth Review

阶段成长总结：

- 训练次数
- 训练变化
- 代表性突破

## WorkBuddy 使用示例

输入：

> 今天练胸，上斜30kg三组，卧推60kg两组、70kg两组、80kg两组，第一次完成80kg。

AI整理：

```text
日期：2026-09-05
训练部位：胸
动作：卧推 60kg×2、70kg×2、80kg×2
训练感受：首次完成80kg突破
```

并沉淀到腾讯文档。
